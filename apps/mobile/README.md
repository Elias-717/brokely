# apps/mobile

The Brokely Android app: React Native + Expo, using **development builds** (decision D-10).
Expo Go is not used, because release 0.2 adds a native Kotlin TNG notification listener.

## Status

Not created yet. The Expo project is generated on a developer machine (it needs the npm registry and
picks the current Expo SDK). From the repo root:

```bash
pnpm create expo-app apps/mobile --template blank-typescript
cd apps/mobile
npx expo install expo-dev-client
```

Then in `app.json`:

- set `"name": "Brokely"` and `"slug": "brokely"`
- set `android.package` to `"com.brokely.app"`

Add the shared packages. Run this **from the repo root** (running a plain `pnpm add` in the root
fails with `ERR_PNPM_ADDING_TO_ROOT`, which is correct: never add app dependencies to the root).
In PowerShell keep the quotes, because `@` and `*` are special characters there:

```bash
pnpm --filter ./apps/mobile add "@brokely/domain@workspace:*" "@brokely/contracts@workspace:*"
```

## Running on a phone

```bash
npx expo run:android      # local development build (needs Android Studio / SDK)
# or
npx eas-cli build --profile development --platform android   # cloud build with EAS
```

`android/` and `ios/` are generated by `expo prebuild` and are not committed (see `.gitignore`).

## Planned structure (Phase 3)

- `app/` — Expo Router screens: Home, Records, Insights, Debts, Plan, Settings (PRD section 10)
- `src/db/` — expo-sqlite + Drizzle schema, migrations and repositories (record + outbox in one transaction)
- `src/sync/` — outbox and sync loop (Phase 4)
- `modules/tng-listener/` — Kotlin NotificationListenerService via the Expo Modules API (release 0.2)
