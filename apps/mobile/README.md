# apps/mobile

The Brokely Android app: React Native + Expo, using **development builds** (decision D-10).
Expo Go is not used, because release 0.2 adds a native Kotlin TNG notification listener.

## Status

Generated from the `blank-typescript` template (Expo SDK 58) with `expo-dev-client`.
`app.json`: name `Brokely`, slug `brokely`, Android package `com.elias717.brokely`, linked to an EAS project.
`@brokely/domain` and `@brokely/contracts` are added as workspace dependencies.

To add more workspace packages later, run from the repo root (a plain `pnpm add` in the root fails
with `ERR_PNPM_ADDING_TO_ROOT`, which is correct). In PowerShell keep the quotes:

```bash
pnpm --filter ./apps/mobile add "@brokely/<package>@workspace:*"
```

## Running on a phone

Run these **inside `apps/mobile`** (`cd apps/mobile`), never at the repo root. Local builds need
`ANDROID_HOME` pointing at the Android SDK (usually `%LOCALAPPDATA%\Android\Sdk`) and the phone
connected with USB debugging on (`adb devices` should list it).

```bash
npx expo run:android      # local development build (needs Android Studio / SDK)
# or
npx eas-cli build --profile development --platform android   # cloud build with EAS
```

`android/` and `ios/` are generated by `expo prebuild` and are not committed (see `.gitignore`).

## Structure

- `app/` — Expo Router screens. `_layout.tsx` runs the database migrations before any screen;
  `(tabs)/` holds Home · Records · (+) · Insights · More (D-24); the centre + opens `quick-add`
  as a modal. With no categories yet the app opens `welcome` (first run, D-23).
- `src/db/client.ts` — opens `brokely.db` (expo-sqlite), turns foreign keys on, and builds the
  repository context (UUIDv7 IDs, clock). All writes go through `@brokely/local-db` repositories.
- `src/db/use-read.ts` — `useRead(db => …)` re-runs a read after any database change.
- `src/ui/` — placeholder grey wireframe look; colours and fonts are not decided yet.
- Migrations come from `@brokely/local-db/migrations`. After changing `packages/local-db/src/schema.ts`
  run `pnpm --filter @brokely/local-db db:generate`. `.sql` files are bundled by
  `metro.config.js` + `babel.config.js` (inline-import).
- Later: `src/sync/` (Phase 4), `modules/tng-listener/` (Kotlin, release 0.2).

To check the app bundles without a phone: `CI=1 npx expo export --platform android`.
